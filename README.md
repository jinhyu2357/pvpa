# pvpa

Paper 서버용 1:1 PvP 허용 관리 플러그인입니다.  
1v1상태에서 다른 플레이어와 새로운 pvp관계를 형성할 수도 있습니다.  
기본적으로 플레이어 간 공격을 차단하고, 서로가 명시적으로 허용한 경우에만 PvP가 가능하도록 동작합니다.

## 주요 기능

- **상호 동의 PvP**: 공격자/피격자 **양쪽 PvP 허용 목록**에 서로가 있어야 타격이 허용됩니다.
- **요청/수락 흐름**: `/pvp` 로 요청, `/pvpa` 로 수락하는 구조로 안전하게 PvP를 활성화합니다.
- **즉시 해제**: `/pvpc` 로 허용/대기 상태를 정리해 PvP 관계를 빠르게 끊을 수 있습니다.
- **PvP 목록 조회**: `/pvplist` 로 현재 허용 목록을 채팅으로 확인할 수 있습니다.
- **스코어보드 표시 토글**: `/pvpshow` 로 PvP 허용 목록을 사이드바에 표시/숨김할 수 있습니다.
- **투사체 지원**: 근접 공격뿐 아니라 플레이어가 쏜 투사체 공격도 동일 규칙을 적용합니다.
- **내구도 소모 방지**: 허용된 PvP 전투 직후 짧은 시간 동안 아이템 내구도 감소를 취소합니다.

## 명령어

| 명령어 | 설명 | 사용법 |
|---|---|---|
| `/pvp` | 대상에게 PvP 요청 전송 + 내 허용 목록에 대상 추가 | `/pvp <name>` |
| `/pvpa` | 대상이 보낸 PvP 요청 수락 + 내 허용 목록에 대상 추가 | `/pvpa <name>` |
| `/pvpc` | 양쪽 허용 목록/요청 목록에서 관계 해제 | `/pvpc <name>` |
| `/pvplist` | 내 PvP 허용 목록 출력 | `/pvplist` |
| `/pvpshow` | PvP 목록 스코어보드 표시 토글 | `/pvpshow` |

### 동작 규칙 요약

1. 공격이 성립하려면 두 플레이어가 서로를 허용해야 합니다.
2. `/pvp A` 실행 시, 요청자는 A를 허용 목록에 추가하고 A에게 요청이 생성됩니다.
3. 요청 대상이 `/pvpa` 로 수락하면 상호 허용 상태가 되어 PvP가 가능해집니다.
4. `/pvpc` 는 허용 목록과 대기 요청(양방향)을 함께 정리합니다.
